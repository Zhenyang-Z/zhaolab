## Squarespace 动态功能与替代

访客正文中未发现需迁移的表单、搜索、登录或支付模块。快照中的 Stripe、账户/商店样式属于编辑后台，不能据此认定课题组网站有支付业务，已剔除。

Squarespace 可视化编辑器、后台账号、云端保存、平台统计和页面编辑控件不能作为静态代码迁移。现在用独立 JSON + Python 构建替代后台编辑；Git 保存版本；GitHub Pages 提供静态托管。菜单用本地 JavaScript 实现，无脚本时仍可使用导航。原资料未提供可独立恢复的动画/灯箱行为，图片直接展示。

若以后确需收件表单，可连接自选表单服务或服务端函数；当前招聘用原有邮箱链接。若需要多人图形化编辑，可再接入 Git 型 CMS；访问统计可另行配置。上述可选服务未接入，不引入默认账号、追踪代码或假提交功能。
